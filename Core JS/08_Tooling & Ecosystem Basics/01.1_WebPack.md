# Webpack

Webpack is a JavaScript bundler used to build modern web applications.

## What Webpack does

It starts from one or more entry points, finds all the files they depend on, processes them, and emits final bundles that can run in the browser.

## Core concepts

### Entry

The entry point tells webpack where to start building the dependency graph.

```js
module.exports = {
  entry: './src/index.js',
};
```

### Output

The output tells webpack where to place the generated bundle.

```js
module.exports = {
  output: {
    filename: 'bundle.js',
    path: __dirname + '/dist',
  },
};
```

### Loaders

Loaders transform files that are not JavaScript. For example:

- CSS files
- SCSS files
- TypeScript files
- images and fonts

```js
module.exports = {
  module: {
    rules: [
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader'],
      },
    ],
  },
};
```

### Plugins

Plugins extend webpack behavior beyond bundling. They can inject HTML, optimize assets, clean folders, and set environment variables.

Examples:

- HtmlWebpackPlugin
- MiniCssExtractPlugin
- DefinePlugin
- CleanWebpackPlugin

### Mode

Webpack supports different build modes:

- `development`
- `production`

```js
module.exports = {
  mode: 'production',
};
```

## Development mode vs production mode

### Development mode

- faster builds
- source maps enabled
- easier debugging
- not minified

### Production mode

- minified code
- optimized assets
- smaller output size
- better performance for deployment

## Source maps

Source maps help you debug code after it has been transformed or bundled.

```js
module.exports = {
  devtool: 'source-map',
};
```

## Why webpack is important

Webpack is useful when an app has:

- lots of modules
- CSS and asset imports
- Babel or TypeScript transformations
- code splitting and optimization needs
- deployment builds for production

## Example webpack workflow

Typical workflow:

1. Start with an entry file
2. Resolve imported modules
3. Apply loaders and plugins
4. Bundle everything together
5. Emit output in the dist folder

## Common webpack tasks

- transpile JS with Babel
- handle CSS with loaders
- process images and fonts
- add source maps for debugging
- minify output for production

## Short interview answer

Webpack is a bundler that takes source files, resolves their dependencies, applies transforms, and emits optimized files for the browser. It is useful for large and complex applications that need modular code, assets, and production optimization.

## Summary

Webpack is one of the most important toolchains in frontend development because it handles module bundling, asset processing, optimization, and build workflows in a single system.
